Component Owner:

Grady Cate

Description:

The effects component manipulates and processes audio that is generated by the synthesizer. Effects are then applied in audio generation rather than after rendering. The synthesizer uses buses. Each XML note controls how much of the audio is sent through each bus. It is then processed and mixed into the output.

Ring modulation multiplies the input using an oscillator. This produces an additional frequency, leacing a metallic, electronic sound. The noise gate compares the input amplitude against a specific threshold. Anything below said threshold is suprressed, while anything above is allowed to play.

The limiter keeps amplitude from an audio signal from exceeding some specified threshold. This allows for the controlling of unusually loud samples. Then finally, flanging combines the original audio witha delayed version. This produces a sweeping sound.
