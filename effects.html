Prerecorded and downloaded .wav files are loaded into tables. Then, the Generate() function reads each frame from the chosen table. The speed at which this is played back is controlled by a pitch multiplier. Increasing this raises the pitch, where as decreasing lowers it. As for polyphony, the synthesizer supports the ability for multiple drum notes to be played over one another and still be noticeable and heard. Each note creates different instrument instances, allowing this to happen.

The kick is created through synthesization and is not prerecorded as are the other instruments. It is created using a sine wave that exponentially decreases amplitude and frequency. This reproduces the sound of a kick drum.
